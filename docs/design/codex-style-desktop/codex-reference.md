## 2. Codex 关键设计特征解剖 (8 大核心特征)

通过对 Codex 桌面端工作流的观察，提取出以下 8 项核心设计特征：

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 极简弹性工作区 │ 2. 克制视觉语言   │ 3. 一体化 Composer 输入区       │
│ (三栏/两栏随宽度自适应)│ (单强调色/低饱和) │ (自动高度/模式切换/IME 安全)   │
├───────────────────┼───────────────────┼────────────────────────────────┤
│ 4. 思考与工具折叠 │ 5. 真实确定性状态 │ 6. 交付物沉浸承接              │
│ (渐进披露/不扰阅读)│ (拒绝虚假进度条)  │ (即点即看/与来源会话绑定)      │
├───────────────────┼───────────────────┴────────────────────────────────┤
│ 7. macOS 原生融合 │ 8. 紧凑视窗优雅降级 (800x600 依旧具备完整工作流)   │
│ (系统窗口/快捷键) │                                                    │
└───────────────────┴────────────────────────────────────────────────────┘
```

1. **三栏与两栏弹性工作区 (Workspace Architecture)**：
   - 导航侧栏极度轻量，仅呈现会话与核心入口；中心对话区固定居中最大阅读宽度（约 720-760pt），防止超宽屏下文字单行溢出阅读视距；右侧提供按需唤出的检查器/详情抽屉。
2. **安静克制的视觉语言 (Quiet & Craft Visuals)**：
   - 全局界面无大面积高饱和色彩，无渐变描边和厚重阴影；仅保留一个清晰的系统强调色（Accent Blue）；背景通过低透明度的表面层级（Window / Sidebar / Card）区分。
3. **一体化集成 Composer 输入区**：
   - 底部输入框兼具“自然语言输入、模式切换（对话 vs 执行）、状态感知与发送控制”，支持多行平滑自适应，中文输入法组合期间（IME Composing）严密保护不误发。
4. **思考过程与工具调用的渐进式披露 (Progressive Disclosure)**：
   - 漫长的推理思考（Chain of Thought）与冗长工具日志默认收拢为单行药丸状态胶囊，生成中显示微光脉冲，完成后支持一键展开；不让中间过程霸占正文主视觉。
5. **执行过程中的真实确定性状态**：
   - 绝不使用捏造的“百分比进度条（如 35%... 70%）”，而是以真实事件驱动的“动作摘要（如正在读取 package.json...）”展示进度；错误直接提供明确归因与下一步。
6. **交付物与代码产物的即时承接**：
   - 生成的代码块提供纯净复制；生成的文件与链接（Artifacts）稳定挂载，并在右侧详情或正文末尾呈现直达入口。
7. **macOS 原生平台深度融合**：
   - 采用系统统一标题栏，交通灯按钮原生预留安全区；标准快捷键与菜单栏指令高度齐备，自动无缝适配系统浅色/深色外观。
8. **紧凑窗口下的优雅降级**：
   - 当窗口缩紧至较小尺寸（如 800×600）时，自动收拢侧栏与右侧面板，始终保障中央对话阅读区拥有至少 480pt 以上可用宽度，不发生内容横向截断。

## 3. Codex 对标实现与刻意差异表 (Feature Mapping & Deliberate Differences)

Vesta 在对标 Codex 优秀视觉与交互的同时，必须立足于自身产品的核心定位（**具备 Computer 跨应用操作能力、只读长程记忆、定时自动化与安全审批流的系统级智能体**）。下表严格对照两者的设计实现、用户收益及刻意差异：

| 序号 | 观察维度与参考特征 | 用户核心收益 | Vesta 对标实现 | 刻意差异与决策依据 (Deliberate Differences) | 验证方式与验收证据 |
|---|---|---|---|---|---|
| **01** | **工作区三栏布局**<br>(侧栏+正文+检查器) | 界面层次清晰，宽屏下任务信息与产出一览无余，无需频繁切屏。 | `App.tsx` 构建 `Sidebar` (240pt) + `Center Workspace` (居中限宽 760pt) + 可选 `Inspector` (320pt)。 | **刻意差异**：Codex 侧重于项目代码树与 Git Worktree；Vesta 聚焦于“当前任务步骤（Plan/Steps）+ 工具调用轨迹 + 生成的 Artifacts 交付物”，更契合 Agent 综合任务流。 | 调整窗口宽度至 1440pt、1200pt、900pt 实测三栏与两栏切换流畅度。 |
| **02** | **安静视觉与 Token 体系**<br>(克制用色与浅深自适应) | 减少长时间使用的视觉疲劳，消除花哨装饰对工程思考的打扰。 | 制定精确 CSS 语义 Token（`--surface-*`, `--text-*`, `--accent-*`），浅色灰白与深色炭灰对比度严格 ≥ 4.5:1。 | **刻意差异**：Vesta 增加 `@media (prefers-contrast: more)` 增强对比度分支；状态反馈统一加入“形状图标+文案”，不依赖单一色彩。 | WCAG AA 对比度换算工具核验文本对比度；系统深浅外观切换验证。 |
| **03** | **Composer 输入区体验**<br>(高度自适应与模式切换) | 意图输入丝滑，长文本自如展开，模式切换快捷。 | 基于原生 textarea 封装，单行 44pt 渐进撑高至 200pt，支持 Normal / Plan 分段切换，草稿按会话保留。 | **刻意差异**：严格注入 `isComposing` 中文输入法防护逻辑，防止中文拼音选词回车误触提交；Plan 模式显式引导用户建立多阶段规划。 | 中文拼音输入法输入长句连续回车测试；会话切换草稿复原验证。 |
| **04** | **思考与过程渐进披露**<br>(Thinking/Reasoning 收拢) | 保证正文最终结果清晰可读，同时需要诊断时可快速下钻。 | `AssistantReasoning` 默认收拢为微光脉冲胶囊，完成后展示“已思考 N 秒”，平滑过渡展开。 | **刻意差异**：Vesta 将“模型思考”与“外部工具调用卡片（Tool Call）”分为独立两层展示，工具卡片自带耗时与入参折叠，比纯文本日志更具结构感。 | 触发带 Reasoning 的长文本回复，观察折叠/展开动画与排版层级。 |
| **05** | **真实事件驱动状态**<br>(当前动作与执行控制) | 用户时刻清晰系统在干什么，杜绝黑盒盲等与虚假等待焦虑。 | 工具栏中央常驻状态胶囊（Running / Idle），卡片实时呈现当前正在执行的动作名称与耗时，提供中断/停止按钮。 | **刻意差异**：Vesta 后端基于真实 JSON-RPC 与 WebSocket 广播，状态枚举与后端 DTO 严格 1:1，绝对不引入假百分比倒计时。 | 模拟耗时 10 秒的后台命令，核验状态文案与按钮状态实时性。 |
| **06** | **审批交互与浮窗机制**<br>(高危系统操作拦截) | 涉及本地文件删除、命令执行时给予用户绝对知情权与拦截权。 | 主界面当前工作卡片提供醒目审批条，同时支持独立的后台无焦点审批浮窗（`ApprovalFloatingWindow`）。 | **刻意差异（核心特色）**：Codex 主要在编辑器内进行文件 diff 确认；Vesta 支持操作系统级控制（Computer），特设 `focusable: false` 的系统级置顶无焦点浮窗，不夺取用户其他工作应用的键盘焦点。 | 在第三方终端中前台打字，触发 Vesta 审批，验证打字不中断。 |
| **07** | **独立交付物入口**<br>(Artifacts 沉浸管理) | 任务生成的关键文件、报告、图表永久留存，随时打开。 | 检查器设有专门的 Artifacts 清单，侧栏设有全局“交付物”汇总页，支持直达来源会话与系统调用打开。 | **刻意差异**：Vesta 交付物受控于 Host 媒体路由（`/api/artifacts`），不直接向前端暴露本地不可信绝对路径，增强安全沙箱边界。 | 生成文件交付物，核对能否一键唤起预览并定位来源会话。 |
| **08** | **紧凑视窗自适应 (800×600)**<br>(小屏响应式折叠) | 支持小屏笔记本（如 13 寸 MacBook）或分屏并排高效使用。 | 媒体查询动态响应：宽度 < 1100pt 收起 Inspector，宽度 < 900pt 收起 Sidebar，正文保证 ≥ 480pt。 | **刻意差异**：收起侧栏后，顶部工具栏保留极简图标导航开关，不产生信息死胡同，单手或键盘随时呼出抽屉。 | 窗口拉伸测试 800×600 临界点，确认无布局错位、无文字重叠。 |

## 4. 总结：Vesta 的独特性与设计自制

通过本对标分析，Vesta 确立了清晰的演进路径：
1. **学其神，不抄其形**：学习 Codex 安静克制的信息节奏、渐进式披露的思考组织以及沉浸高效的输入流程；
2. **守其道，扬己之长**：坚守 Apple HIG macOS 设计规范与无障碍底线，依托 Vesta 原生的系统控制（Computer）、多阶段规划（Plan）、跨应用无焦点审批等独特优势，打造兼具优雅质感与工程深度的专业级智能工作台。
